# Historical evidence and current limits

The [sanitized ledger](HISTORICAL_EVIDENCE.json) preserves exact identities,
denominators, counter semantics and references to private originals. These
retired systems differ from today's offline CLI. Reproduction checks arithmetic;
it does not rerun models or establish current agent benefit.

- September 18, precompiled context: AGY reported 1,700,615 → 953,118 tokens
  (−43.95%), seven tasks with one pair each, always control first. Codex/Gateway
  reported 504,945 → 287,417 (−43.08%), three tasks with one pair each. Context,
  instructions and integration were confounded. AGY task 4 increased tokens
  by 19.49%; task 6 increased recorded duration despite fewer tokens. Recorded
  omissions remained in AGY task 7 and Gateway task 5.
- Autonomous MCP's separate report recorded 494,700 → 1,372,738 (+177.49%).
  Those totals were not independently recounted from raw events in this review.
- The retired September 21 client matrix was PARTIAL. Linux/WSL2 and Windows
  receipts belong to that candidate and include skips. They do not certify
  current cross-platform support.
- October 3, HTTPX: one question and two treatment/control pairs reported
  179,433 → 304,636 tokens (+69.78%), 8 → 14 commands and 57.73 → 83.29 seconds.
  One treatment answer omitted a required relationship. The runtime commit is
  unavailable in that retained report. A separate preliminary failed capture is
  outside the four-run totals, not silently absorbed into a success summary.

AGY reports cache reads separately from input-plus-output tokens; Codex includes
cached input in input. Do not double-count, pool providers or infer billing costs.
Post-hoc scoring, small samples and missing repeats prevent general conclusions.
Withdrawn zero-failure/all-task-savings claims and flawed gateway file counts
remain documented in the original private evidence. Separate payload-format
reductions of 7.48%/19.57% measured bytes, not an independent native-agent baseline.

The maintained CLI narrows scope to literal source, byte budgets, aliases,
known-symbol coverage and selected-file verification. Expansion has a conservative
64-byte reserve and can remain partial even if a tighter full packet would fit.
Shared text does not establish shared imports, constants or behavior. See
[reproducible examples](USE_CASES.md) and [context handoff](CONTEXT_HANDOFF.md).
A new controlled agent experiment would be needed to establish current benefit.
